## WorkBuddy 国内/国际双账户拆分方案

### 语义定案
- `workbuddy`（tool id 不变，`~/.workbuddy-ai`）= **WorkBuddy 国际版**
- 新增 `workbuddy-cn`（`~/.workbuddy`）= **WorkBuddy 国内版**——独立适配器、独立 source 行、独立会话/用量统计、UI 独立 Tab
- 上一轮的 `home:` 前缀双根机制**撤销**（那是"同账户双安装"的错误语义）；真机库里已入的 `home:` 资产重扫后自动标记 missing 自然消失

### 改动清单

**适配器层**
1. `workbuddy.ts`：回退为单根（保留 walkWorkbuddyBase 重构但去掉第二根扫描与 resolve/home: 逻辑），displayName 改 `WorkBuddy 国际版`
2. 新建 `workbuddy-cn.ts`：id `workbuddy-cn`，displayName `WorkBuddy 国内版`，复用 walkWorkbuddyBase（从 workbuddy.ts export，prefix=''），detect 用 `resolveToolRoot('workbuddy-cn')`，parse 同款（jsonl + workbuddy.db）
3. `roots.ts`：`workbuddy.home` 键改为 `{ key: 'workbuddy-cn', tool: 'workbuddy-cn', label: '国内版根（~/.workbuddy）', env: 'WALLE_WORKBUDDY_CN' }`
4. `index.ts`：adapters 数组加入 workbuddyCnAdapter

**UI 层**（logo 复用 workbuddy.svg，靠文字区分）
5. `Overview.vue` / `Assets.vue` / `Settings.vue`：toolLabel/toolLogos/TOOLS/toolOrder 补 `workbuddy-cn`（'WorkBuddy 国内版'），原 workbuddy 标签改 'WorkBuddy 国际版'

7. `Skills.vue`：TOOLS 加国内版；LINK_TOOLS 加 `workbuddy-cn`；导入向导 TARGET_DEFS 加一行（hint `~/.workbuddy/skills`）

**测试/固件**

**文档**
